# Aryan X Alarm

Brand: ARYAN X NET
Developer: Aryan

## What it does
- Set an alarm time
- Add an alarm label
- Repeat daily or run once
- Shows a high-priority notification
- Saves alarms locally
- Attempts to restore alarms after phone restart
- Uses the supplied Aryan photo in the app

## Build the APK
Open this folder in Android Studio.
1. Let Gradle sync/download dependencies.
2. Build > Build APK(s).
3. The debug APK will normally be under:
   app/build/outputs/apk/debug/app-debug.apk

For a public release, create a signed release APK from Android Studio.

## Important about the download link
A normal web link cannot silently install an Android APK. The user must download it and confirm installation (and Android may ask for permission to install apps from that source).

After building app-debug.apk, upload that APK to a file/release host and put its download link on your website.
